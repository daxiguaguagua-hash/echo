# 元工作流: 自主执行

用户给高层方向后离开。**这不是独立流程，而是在用户授权缺席时自动组合其他工作流。**

**类型**: 元工作流 — 本身不定义步骤，定义如何组合其他流程。

## 触发条件

- 用户明确说"你们自己决定"
- 用户说"我先离开一下"
- 用户授权自主决策

## 组合规则

```
用户授权缺席
  │
  ├─ 有数据问题？ → 先走【数据审计】
  ├─ 有架构决策？ → 先走【跨模型审查】
  ├─ 新模块？     → 走【TDD + Codex 测试】
  ├─ 多步骤？     → 走【Issue 驱动】
  └─ 所有步骤结束 → 过【两条横切门禁】
```

## 内部原则

- **框架优先**: 先修框架问题，再加功能
- **先提交再继续**: 完成一个逻辑单元就 commit
- **内部协商**: Claude 和 Codex 互相审查，不等待用户
- **最终汇报**: 用户回来时给出清晰总结
