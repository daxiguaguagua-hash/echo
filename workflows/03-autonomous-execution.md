# 工作流 3: 自主执行

用户给高层方向后离开，Claude + Codex 自组织完成全部工作。

## 触发条件

- 用户明确说"你们自己决定"
- 用户说"我先离开一下"
- 任务有明确目标但实现路径需要探索

## 流程

```
1. 用户给出方向 + 约束
2. Claude 分析现状（ECHO_STATUS.md + echo MCP）
3. Claude + Codex 协商任务优先级
4. 内部决策（不等待用户确认）
5. 并行执行:
   - Claude 做框架/清理工作
   - Codex 写测试或做独立审查
6. 持续提交（WIP commits）
7. 完成后汇报总结
```

## 关键原则

- **框架优先**：先修框架问题，再加功能
- **先提交再继续**：完成一个逻辑单元就 commit，不攒着
- **遇到阻塞时内部协商**：Claude 和 Codex 互相审查
- **最终汇报**：用户回来时给出清晰的状态总结
